# Preethi ♥ Aakash — Our Little Universe 💖

A little website of memories, games and surprises, made by Preethi for Aakash.

## Run it
Just open `index.html` in a browser. No build step needed.

## Put it on GitHub + Vercel
```bash
cd preethi-aakash
git init
git add .
git commit -m "Our little universe 💖"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main
```
Then import the repo in Vercel (Framework preset: **Other**) and deploy.

## Customise
- Special date: change it in the date box on the page, or edit `start='2024-01-01'` in `index.html`.
- Memories, love notes and the letter are plain text inside `index.html`.
